# 月度消费报告 设计

## 目标

在本机按月查看 5 张卡（楽天 / 三井住友 / Amex / AEON / PayPay）的消费，并把网购单独拆出来：

- **Amazon**
- **楽天系**（楽天市場各店铺、楽天ブックス 等）
- **普通**（其余全部）

用途：用户兼做买取（转卖），网购大多是进货，需要和日常开销分开看。

## 用法

```bash
bun run report        # 生成 data/report.html，用浏览器直接打开
```

`sync` 与 `import` 跑完后自动重新生成报告，不必手动执行。

报告只写在 `data/`（已 gitignore，权限 700），不上传、不启动服务。

## 月份口径

按每笔明细的**消费日（利用日）**归月，不用各家卡自己的账单月（各家含义不同，同一笔会差 1–2 个月）。

数据最早的一两个月可能只有部分卡覆盖，报告底部列出每张卡的消费日覆盖范围供判断。

## 统一字段

新增模块把各家原始字段转成统一结构：

```ts
type Spend = { card: string; date: string /* YYYY-MM-DD */; month: string /* YYYY-MM */; shop: string; amount: number; group: "amazon" | "rakuten" | "normal" };
```

各家取法（查表实现）：

| 卡 | 消费日 | 金额 | 店名 | 跳过的行 |
|---|---|---|---|---|
| rakuten | `利用日`（YYYY/MM/DD） | `利用金額` | `利用店名・商品名` | 消费日为空的续行（海外消费等的补充行） |
| smbc | `cols[0]`（YYYY/M/D 或 YYYY/MM/DD） | 从右往左第 5 列（店名可能含未加引号的逗号，列数不固定） | `cols[1]` | — |
| amex | `ご利用日`（YYYY/MM/DD） | `金額`（去千分位逗号） | `ご利用内容` | `前回分口座振替金額`（上期还款，不是消费） |
| aeon | `useDate`（YYYYMMDD） | `useAmount`（数字，折扣后实付） | `useStoreName` | — |
| paypay | `利用日/キャンセル日`（YYYY/M/D） | `利用金額` | `利用店名・商品名` | — |

- 金额一律用「利用金額」（购买金额，不含分期手续费）。
- 退款、返现为负数，照常计入所在分组，抵扣当月。
- 金额或日期解析不出来的行不静默丢弃：计入报告底部的「未能解析」计数，便于发现格式变化。

## 分组规则

店名先做 NFKC 规范化（全角 / 半角统一，如 `ＡＭＡＺＯＮ` → `AMAZON`、`ﾗｸﾃﾝ` → `ラクテン`），再按顺序匹配，第一条命中即止：

1. 含 `楽天モバイル` → 普通（通信费，不是网购）
2. 含 `アマゾン` 或 `AMAZON`（不区分大小写） → Amazon
3. 含 `楽天` 或 `ラクテン` → 楽天系
4. 其余 → 普通

规则用有序表实现，新增例外只需加一行。

## 页面

单个自包含 HTML 文件，无外部依赖（不加载 CDN），数据以 JSON 内嵌。

1. **月度堆叠柱状图**：每月一根柱，分 Amazon / 楽天系 / 普通 三段，柱顶标合计。用 CSS/SVG 绘制。
2. **月度表**：每月一行，列为 Amazon / 楽天系 / 普通 / 合计。
3. **月份明细**：点开某月，按三组分别列出每笔（日期、卡、店名、金额），每组带小计，组内按日期排序。
4. **底部说明**：各卡消费日覆盖范围、未能解析的行数。

金额统一显示为日元整数加千分位。

## 模块划分

| 文件 | 职责 |
|---|---|
| `src/spend.ts` | 原始行 → `Spend`（各卡取法表、跳过规则、分组规则） |
| `src/report.ts` | 读库 → `Spend[]` → 按月汇总 → 生成 HTML 字符串并写入 `data/report.html` |
| `src/cli.ts` | 新增 `report` 命令；`sync` / `import` 结束后调用生成 |

`spend.ts` 不依赖数据库和文件系统，便于测试。

## 测试

在 `src/core.test.ts` 增加：

- 每家卡各一条典型行的转换（日期、金额、店名）
- 跳过：楽天续行、Amex `前回分口座振替金額`
- 三井住友店名含逗号时仍取对金额
- 分组：全角 `ＡＭＡＺＯＮ．ＣＯ．ＪＰ`、半角 `ﾗｸﾃﾝｲﾁ`、`楽天モバイル通信料` 归普通、负数退款仍在原分组
- 按月汇总：跨月、负数抵扣

## 不做

- 手动标记某笔为买取 / 普通
- 导入 Amazon 订单以区分品类
- 本地服务、筛选、搜索
